# VSTEP Reading – Shopping & Money | Student Version

Tất cả các tệp trong ZIP nằm ở thư mục gốc. Giải nén rồi upload từng file lên GitHub (main / root).

Trang mặc định: index.html.

Student: chỉ báo đúng/sai khi Check; không có giao diện hiển thị đáp án/Evidence.

Hình thức: 4 passages, 40 Reading Questions + 40 Paraphrase Challenge (luyện tập bổ sung), không có Warm-up.

Chú ý: đáp án vẫn nằm trong JavaScript và có thể xem bằng công cụ phát triển trình duyệt khi trang công khai. Đây là trang luyện tập, không phù hợp làm thi có yêu cầu bảo mật đáp án.
